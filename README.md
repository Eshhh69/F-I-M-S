# File Integrity Monitoring System (FIMS)

A lightweight Python-based File Integrity Monitoring System that detects file creation, modification, and deletion using SHA-256 hashing.

## Features

- Real-time monitoring
- SHA-256 hashing
- Baseline generation
- Detects created, modified and deleted files
- Timestamped alerts

## Requirements

- Python 3.10+

## Installation

```bash
git clone https://github.com/yourusername/F-I-M-S.git
cd F-I-M-S
pip install -r requirements.txt
python monitor.py
```
